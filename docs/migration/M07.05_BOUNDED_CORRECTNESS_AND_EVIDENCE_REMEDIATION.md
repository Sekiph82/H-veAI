# M07.05 Bounded Correctness and Evidence Remediation

## Scope

M07.05 closes the active strict-audit findings from M07.04 and incorporates the
manual QA identity and single-viewport corrections. It does not begin M08.

## Implemented controls

- Ordinary watcher events do not clear a rescan requirement; only an explicit,
  successful rescan does.
- Rescan success is gated by watcher availability, and watcher roots are tracked
  so path changes reattach the watcher.
- Legacy rowless Git projects fail closed during repair.
- Binary diff evidence comes from git diff --numstat and uses the real path.
- Migration v5 retains its historical body; migration v7 normalizes
  project_snapshots.created_at.
- Live Tauri UI identity comes from the Project Registry. Loading, ready,
  not-found, and error route states do not substitute FormuLab or another
  fixture identity.
- The Command Center keeps its canonical single viewport, bounded panels,
  220px desktop sidebar, distinct topbar surfaces, global Akilta footer, and
  live registry counts.
- The publisher builds Tauri production mode with --no-bundle, waits for the
  frontend-ready marker, smoke-tests candidate and stable paths, validates the
  shortcut and icon, and rolls back on publication failure.

## Gate result

The frontend suite (11 tests), Rust suite (50 tests), formatting, typecheck,
frontend build, and hardened publisher smoke pass. M07.05 remains FAIL because
the independent focused R01-R15 evidence matrix and user visual acceptance are
not complete. No installer was created and M08 was not started.
