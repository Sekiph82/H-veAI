## Scope

This document records the strict remediation closure for the M07 watcher audit and the open M01-M07 cross-milestone findings. Historical PASS or COMPLETE claims were treated as hypotheses and re-tested.

## Finding Closure

- **M07-B01 BLOCKER:** ordinary watcher refreshes now preserve `rescan_required`; only an explicit successful rescan clears it. Failed or missing-root rescans remain degraded.
- **M07-M01 MAJOR:** `relative_path` now requires `strip_prefix(root)` and rejects outside paths, traversal paths, and rename pairs with an outside endpoint.
- **M07-M02 MAJOR:** direct unit coverage includes bounded overflow, outside-root containment, rename rejection, real notify delivery, missing-root behavior, manager cleanup, and explicit rescan semantics.
- **M06 binary diff:** Git diff no longer requests raw binary patch payloads; binary changes are metadata-only and textual hunks remain bounded.
- **M05 timestamps:** native timestamps use RFC3339 UTC milliseconds; migration 5 converts numeric legacy values and preserves malformed values.
- **M05 repair identity:** Git/non-Git type changes, remote disappearance, remote changes, and conflicting HEAD evidence fail closed. Sanitized equivalent remote credentials remain comparable.
- **M04 SQLite:** foreign keys, WAL, `busy_timeout=5000`, `synchronous=NORMAL`, startup `quick_check`, and pre-migration atomic backup are enforced.
- **M03 dead code:** module-wide runtime suppression was removed. Remaining warnings identify intentionally dormant enum variants and public native-boundary helpers.
- **M01/M02 CSP:** production CSP has no localhost or websocket origins and no wildcard sources. `devUrl` remains the separate Tauri development loader setting.
- **M01 restart:** native restart command remains implemented and permission-gated. Direct and shortcut close/reopen smoke passed; in-app restart click acceptance remains manual/unverified.
- **Visual fidelity:** canonical dashboard asset was inspected and is preserved as the visual reference. Automated build passed; cross-viewport click/screenshot acceptance remains manual/unverified.
- **Stable development launch:** release executable was copied to `H!veAI/dev-bin/H!veAI.exe`; Desktop `H!veAI.lnk` targets that exact file. Direct and shortcut launches were validated and closed cleanly.
