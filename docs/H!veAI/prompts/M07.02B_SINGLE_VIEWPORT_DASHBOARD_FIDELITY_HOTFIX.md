# B01 — BLOCKER — SINGLE-VIEWPORT COMMAND CENTER

The user explicitly requires the primary Command Center / Global Overview to fit in one desktop viewport.

Required:

1. At canonical reference size `1536x1024`, the complete primary overview must fit without outer/body vertical scrolling.
2. At the user's maximized desktop QA size `2048x1280`, the complete primary overview must fit without outer/body vertical scrolling.
3. No outer/body horizontal scroll at either size.
4. Do not solve this merely by shrinking the entire UI with browser zoom or CSS transform scaling.
5. Use a true viewport-height grid/flex composition.
6. Give nested grid/flex children `min-height: 0` where required so bounded internal overflow works correctly.
7. Individual lists/panels may have internal scroll when their data exceeds available space.
8. Do not globally break scrolling on Projects, Cockpit, Settings, or other routes. Apply route-specific Command Center layout behavior where necessary.

Preferred high-level shell behavior:

```text
App viewport
├─ Sidebar (full height)
└─ Main
   ├─ compact topbar
   └─ Command Center viewport grid (remaining height)
```

The Command Center itself must behave like an operational console, not a document page.
