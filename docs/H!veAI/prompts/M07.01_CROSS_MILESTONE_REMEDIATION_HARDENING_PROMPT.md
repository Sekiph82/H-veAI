# PART A — M07 STRICT AUDIT REMEDIATION

## A1 — BLOCKER: preserve rescan-required correctness

Current defect:
- queue overflow/error sets `rescan_required=true`,
- ordinary `refresh_project_snapshot()` can later clear it unconditionally,
- this can falsely return watcher health to normal without explicit reconciliation.

Required correction:
1. `rescan_required` MUST remain true after overflow/error until an explicit rescan/reconciliation succeeds.
2. Ordinary debounce/event refresh MUST NOT clear it.
3. A failed explicit rescan MUST keep it true and keep health degraded.
4. A successful explicit rescan may clear it only after the required evidence refresh completes successfully.
5. Persisted project snapshot state and in-memory status must agree.

Required tests:
- overflow -> `rescan_required=true`
- ordinary accepted event/refresh -> still true
- explicit successful rescan -> false
- explicit failed rescan -> still true
- restart/reload semantics where applicable

## A2 — MAJOR: fail-closed project-root containment

Current defect:
`relative_path()` falls back to the original path if `strip_prefix(root)` fails.

Required correction:
- reject events outside the registered project root,
- never normalize an outside-root absolute path into an internal relative-looking event,
- do not expose outside-root absolute paths to frontend event/status payloads,
- handle Windows separators/case semantics conservatively,
- do not follow a symlink/junction escape in a way that violates registered-root scope.

Required tests:
- in-root path accepted
- sibling/outside-root path rejected
- `..` rejected
- rename with one side outside root handled safely
- absolute path never appears in frontend-facing normalized event

## A3 — MAJOR: close M07 evidence/test gaps

- rename normalization
