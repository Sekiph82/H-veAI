Evidence gap:

- test module still contains only registration/duplicate, archive/remove/repair file safety, and list/search/missing tests. The required identity matrix is absent.

### Git diff

`src-tauri/src/git_engine/mod.rs`

Current product path runs text diff without `--no-textconv`, then separately runs `--numstat`.

The old parser:

```rust
line.strip_prefix("Binary files ")
    .and_then(|value| value.split(" and ").next())
```

can return `/dev/null` for a newly-added staged binary. Adding the real path from `--numstat` does not remove that invalid metadata entry.
